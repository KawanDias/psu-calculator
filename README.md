# PSU Calculator & Bottleneck Analyzer

[Português](#português) | [English](#english)

---

<a name="português"></a>
## 🇧🇷 Português

Aplicação web desenvolvida para estimar o consumo energético (Watts) de configurações de hardware, recomendar a potência ideal de fonte de alimentação (PSU) e analisar o nível de gargalo (*bottleneck*) entre processador (CPU) e placa de vídeo (GPU).

**Link da aplicação:** [https://psu-calculator-xi.vercel.app](https://psu-calculator-xi.vercel.app)

### Recursos e Funcionalidades

* **Dimensionamento de Potência:** Cálculo do consumo total estimado com base no TDP dos componentes principais, aplicando margem de segurança operacional para oscilações de carga.
* **Análise de Eficiência e Gargalo:** Diagnóstico de compatibilidade de desempenho entre CPU e GPU para identificar possíveis limitações de processamento.
* **Mapeamento de Hardware:** Integração com URLs de busca estruturadas para direcionamento a lojas e distribuidores de componentes.
* **Interface Responsiva:** Desenvolvida em arquitetura *Mobile-First* com tema escuro (*Dark Mode*) otimizado para usabilidade.

### Tecnologias Utilizadas

* **Linguagens:** HTML5, JavaScript (ES6+)
* **Estilização:** Tailwind CSS
* **Hospedagem e CI/CD:** Vercel

### Instalação e Execução Local

1. Clone o repositório:
git clone [https://github.com/KawAnDias/psu-calculator.git](https://github.com/KawAnDias/psu-calculator.git)

2. Acesse o diretório do projeto:
cd psu-calculator

3. Execute a aplicação:
Abra o arquivo index.html diretamente em um navegador web ou utilize um servidor local (ex: extensão Live Server do VS Code).

<a name="english"></a>
## 🇺🇸 English

Web application developed to estimate hardware power consumption (Watts), recommend the ideal Power Supply Unit (PSU) wattage, and analyze the bottleneck level between the processor (CPU) and graphics card (GPU).

**Live Application:** [https://psu-calculator-xi.vercel.app](https://psu-calculator-xi.vercel.app)

### Features

* **Power Sizing:** Estimated total wattage calculation based on main component TDP, incorporating an operational safety margin for power spikes.
* **Bottleneck & Efficiency Analysis:** Performance compatibility diagnostic between CPU and GPU to identify potential processing limitations.
* **Hardware Mapping:** Integration with structured search URLs to redirect users to component retailers and distributors.
* **Responsive Interface:** Built with a *Mobile-First* architecture and an optimized dark mode UI for enhanced usability.

### Tech Stack

* **Languages:** HTML5, JavaScript (ES6+)
* **Styling:** Tailwind CSS
* **Deployment & CI/CD:** Vercel

### Local Setup & Installation

1. Clone the repository:
git clone [https://github.com/KawAnDias/psu-calculator.git](https://github.com/KawAnDias/psu-calculator.git)

2. Navigate to the project directory:
cd psu-calculator

3. Run the application:
Open the index.html file directly in any web browser or use a local development server (e.g., VS Code Live Server extension).
